# Nimbus - Angular E-commerce App

Nimbus is a responsive online shopping frontend built with Angular.

## Features
- Product listing
- Product details page
- Shopping cart UI
- Responsive design
- Reusable Angular components
- Clean layout for e-commerce businesses

## Tech Stack
- Angular
- TypeScript
- HTML
- CSS
